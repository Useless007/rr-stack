# Security

Please report a vulnerability privately through
[GitHub security advisories](https://github.com/Useless007/rr-stack/security/advisories/new),
not in a public issue. Include the version of `create-rr-stack` that created the project, what an
attacker can do, and the steps to reproduce.

You will get an answer within a week. Fixes ship as a new `create-rr-stack` release; projects
created earlier need the same change applied by hand, so the advisory will describe it.
